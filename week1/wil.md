# 딥러닝 스터디 1주차

## 머신러닝과 딥러닝
- 머신러닝: 데이터로부터 규칙을 학습해, 새로운 데이터에 대해 예측 및 판단을 하는 알고리즘

- 딥러닝: 머신러닝의 하위 집합으로, 인공신경망 구조를 이용해 자동으로 학습함

- 머신러닝 예시: 생선 길이, 무게로 분류를 하고 예측한다. 
    - Feature: 입력값, Target: 정답?

- 데이터 분리: train/test로 분리 - 일반화하지 않기 위함
    - train: 모델이 데이터 패턴 학습하는데 사용
    - validation: 학습 중 모델의 성능을 확인 및 조정하기 위해 사용
    - test: 모델의 최종 성능을 평가할 때 사용

- 머신러닝 모델: KNN, 선형 회귀, 로지스틱 회귀, 결정 트리, 랜덤 포레스트, SGD Classifier, ANN

## 인공신경망
- 인공지능 > 머신러닝 > 인공신경망 > 딥러닝

### 인공신경망의 구조
- 입력층: 모델이 데이터를 처음 받아들이는 층
- 은닉층: 입력받은 정보를 가중치와 활성화 함수를 이용해 예측에 필요한 특징을 학습하는 층
- 출력층: 은닉층에서 처리된 정보를 기반으로 최종 예측 결과를 출력하는 층

- 여러 입력값 -> 가중치 적용 -> 모두 더하기 -> 활성화 함수 -> 하나의 출력값

### 가중치
- 계수(가중치): 입력값을 얼마나 반영할지 결정하는 값
- 가중치 클수록 결과에 큰 반영

### 활성화 함수
- 뉴런이 계산한 값을 한 번 변환해서 다음 층으로 전달하는 함수
- 이게 없으면, 선형적인 계산만 반복해서 복잡한 패턴을 표현하기 힘듬, 따라서 비선형성 추가

### ReLU
- 음수는 0으로 만들고 양수는 그대로 통과시키는 함수

### Sigmoid
- 각각의 값을 독립적으로 0~1 사이로 변환

### Softmax
- 여러 출력값을 비교해서 전체 합이 1이 되도록 변환
